Context
Why Sonar exists in an AI-first world
The same technology that generates code can be weaponized to scan it for vulnerabilities.
⚠️

The threat

Adversarial LLMs can scan any codebase in seconds to find exploitable flaws. Sonar's Mythos project proved it — AI found 200 zero-day vulnerabilities in popular open-source projects. If Sonar doesn't catch them first, attackers will.

🛡️

Sonar's answer

15 years of deterministic, fixed rules in SonarQube — rules that don't hallucinate, don't skip steps, and can't be fooled. Combined with a new AI layer, Sonar wraps the entire AI coding loop: before, during, and after code generation.

The Framework
AC/DC — Agent Centric Development Cycle
Three phases that wrap every AI coding tool — Guide the agent before it writes, Verify what it produced, Solve what it got wrong.
🔌
What is an MCP Server?
MCP (Model Context Protocol) is an open standard that lets AI agents talk to external tools — Sonar's MCP Server is the plug that connects your AI coding agent (Claude Code, Copilot, Cursor…) directly to SonarQube, so the agent can read your rules, query issues, and run scans without you doing anything manually.

Workflow
A Developer's Day
Where each Sonar product appears — from morning AI session to code in production.
🤖
Morning · AI Agent session
Developer opens Claude Code, Copilot, or Cursor
The MCP Server has already connected the agent to SonarQube. Context Augmentation injects Sonar's rules silently — the agent knows what to avoid before writing a single line. No setup needed by the developer.
MCP Server Context Augmentation ✓ Fully automatic
💻
During the day · Writing in the IDE
Developer writes or reviews code in VS Code / IntelliJ
SonarLint highlights issues in real time — like a spellchecker, but for code security. The new SonarQube CLI (sonar, Beta) goes further from the terminal: sonar verify scans uncommitted changes with Agentic Analysis, sonar analyze secrets hunts for exposed credentials in any file, and sonar analyze dependency-risks runs SCA — all before a single commit.
SonarLint SonarQube CLI Beta ✓ Issues surface automatically
📤
End of day · git push → Pull Request
CI/CD pipeline runs — the full verification suite fires
Agentic Analysis scans the entire diff with AI reasoning. SAST catches security bugs, SCA checks dependencies for CVEs, Secrets Detection flags any leaked tokens. AI Code Assurance certifies AI-generated code. If anything fails, Quality Gate blocks the PR. AI CodeFix suggests a one-click fix inline — developer reviews and approves.
Agentic Analysis SAST SCA Secrets Detection AI Code Assurance Quality Gate AI CodeFix 👤 Dev approves fix
🔧
Async · Unresolved issues & legacy debt
Remediation Agent handles the rest
For issues that weren't fixed inline, the Remediation Agent opens a new PR with the fix already applied. A human reviewer approves it. The loop then restarts with a cleaner, updated context for the next session.
Remediation Agent 👤 PR approval required

Advanced Security
The Hunter Agent — Deep Security Layer
Above and beyond SAST: AI that reasons through your business logic like an attacker would.
Enterprise Alpha · SonarQube Cloud
SonarQube Hunter Agent (SQHA)
Standard SAST matches patterns. The Hunter Agent reasons. It uses Playbooks — structured AI reasoning scripts — to think through code logic the way a security researcher would, catching flaws that fixed rules simply cannot see.
🔓 Broken Access Control & IDOR
Can user A access user B's data by manipulating an ID or parameter?
⚙️ Business Logic Flaws
Does the application's workflow allow unintended actions or sequences?
🔑 Auth & Session Issues
Are sessions, tokens, and authentication flows handled securely end to end?
📋 Playbooks
The AI reasoning scripts that tell the agent how to hunt for each vulnerability type.
200 zero-day vulnerabilities found in popular open-source projects during internal Mythos testing — currently being disclosed ethically.
